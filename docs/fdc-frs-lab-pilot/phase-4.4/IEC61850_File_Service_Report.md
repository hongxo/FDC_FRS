# IEC 61850 File Services

ABI và hành vi được kiểm tra với libiec61850 pin từ source `6e7a603c771d6124cd3cafea7ec38b7e0f2e7aaf`. Adapter chỉ bind các export phục vụ phiên và đọc file. Directory dùng trang giới hạn, kiểm tra cursor, đường dẫn và số entry. Transfer kiểm tra scope, timeout, cancellation và tốc độ. Simulator loopback đã liệt kê và đọc đúng byte fixture.
