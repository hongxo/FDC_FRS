# Device classification

The exact-model lookup identifies S7-1200 as Siemens PLC and REF620, 7SJ85 and P643 as protection-relay candidates. Other recognized models and unknown values are kept separate. The lookup uses the device text only and never uses address ranges. An operator can record a manual confirmation for an accepted row. IEC 61850 and File Services observations are separate from classification.
