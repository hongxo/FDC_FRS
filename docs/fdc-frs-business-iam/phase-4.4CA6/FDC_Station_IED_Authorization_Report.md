# FDC Station IED Authorization Report

List/detail dùng SQL WHERE station scope trước page/filter, kể cả khi người dùng sửa station hoặc object ID. Ngoài scope và object không tồn tại cùng null/404 khi người dùng có quyền operation. Chưa mở search hoặc IED write/discovery. Mandatory deny giữ nguyên.
