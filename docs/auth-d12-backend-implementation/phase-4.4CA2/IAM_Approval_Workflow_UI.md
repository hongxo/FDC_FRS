# Approval workflow

Giữ đọc theo request ID khi server cho phép. Approval status và effective status tách riêng. Chưa map Submit/Review/Approve/Reject/Apply/Revoke. D04/D09 phải chốt delegation, PersonReference SoD, revision/hash, approval evidence, CSRF, If-Match, idempotency và atomic audit. Không có parallel workflow authority.
