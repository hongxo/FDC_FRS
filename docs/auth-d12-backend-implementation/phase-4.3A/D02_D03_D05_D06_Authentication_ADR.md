## Assurance, transaction và compatibility

SQL throttle reservation trước hash; verify expensive proof ngoài long-held SQL locks; completion trong D09 đọc lại credential/security/policy versions để reject proof cũ sau reset. Source AuthenticationService hiện callback hash trong transaction-store abstraction:4.3B phải xử lý lock duration, không chỉ implement interface rồi giữ lock dài. One-use MFA/recovery consume vàfinal session/audit/outbox cùng commit; password proof không được cấp full session trước factor policy.

Session.MfaAt hiện không đủ phân biệt factor/credential/UV/assurance/revoked method. Phải có approved schema/DTO extension trước privileged step-up; không coi timestamp hoặc UI state là factor verification. Shared DP keyring cần cho antiforgery/protected challenge nếu dùng framework; raw opaque handle vẫn do SQL digest/current authority xác minh. Explicit key repository cần ACL và encryption-at-rest riêng.[Microsoft Data Protection configuration](https://learn.microsoft.com/en-us/aspnet/core/security/data-protection/configuration/overview?view=aspnetcore-10.0)

Mất WAN:Collector tiếp tục collection/store-forward, không triển khai human IAM offline tại trạm nếu chưa có business approval. Mất Center/SQL:Human mutations fail-closed; HA nodes cùng authority và key domain, no emergency cached allow. Restore phải tạo epoch mới trước mở listeners; credential/session key restore không được revive quyền đã thu hồi.

Căn cứ tham khảo:NIST hướng dẫn password blocklist/rate limiting và phân biệt password đơn yếu tố; FDC đề nghị min15 cho consistency nhưng assurance/profile cụ thể vẫn owner quyết.[NIST authenticators](https://pages.nist.gov/800-63-4/sp800-63b/authenticators/) WebAuthn verification phải ràng buộc RP/origin/challenge và UV policy; dùng implementation được review, không chỉ kiểm client flag.[W3C WebAuthn](https://www.w3.org/TR/webauthn-3/) Đây là references, không approval hoặc tuyên bố FDC đạt AAL.

Acceptance sau approval:real HTTPS invalid/unknown/locked timing cohorts; shared limiter across2 nodes; real enrollment/assertion/expired/replayed/mismatched RP+origin/UV; recovery self-approval/replay denied; session rotation old-proof deny; logout-all/races; clock skew; key rollout; SQL outage; no raw secrets. Không dùng mock factor để chứng minh.
